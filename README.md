# КОРПУС — публічний веб-інтерфейс

Зібраний фронтенд системи КОРПУС: доказова довідкова система за статутами й
настановами ЗСУ. Кожна відповідь несе точні цитати з посиланням на статтю.

**Тут немає ані джерельного коду системи, ані корпусу документів, ані доказів** —
лише скомпільована сторінка. Операторська поверхня (консоль) до публікації не входить:
її прибирає той самий вивід, яким її прибирає публічна межа.

Відповіді надає окремий сервіс. Коли він недоступний, сторінка відкривається й каже
про це прямо — вона не вдає очікування.
