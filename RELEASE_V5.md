# KORPUS v5.0.0 release scope

v5 integrates the v4 infrastructure-hardened baseline with the complete 99-finding audit package. It adds server-side entitlement projection, need-to-know compartments, browser OIDC/BFF, durable isolated ingestion, source authenticity, near-duplicate and extraction-quality governance, reviewer credential governance, executable corpus data policy, production Kubernetes reference manifests, expanded adversarial tests and 26 hand-selected critical mutation operators.

Release is an engineering assurance baseline. It is not production authorization for restricted or military data. Exact executed metrics and remaining debt are recorded in `VERIFICATION_REPORT_V5.md` and `docs/audit/closure/`.
