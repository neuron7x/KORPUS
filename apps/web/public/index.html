Встановити суб’єкта

OIDC identity та серверні entitlement-проєкції. Не довіряти ролям із request body.

03

Що система доводить — і чого не обіцяє.

Доводить локально

  • недоступний текст не входить у retrieval;
  • цитата зв’язана з immutable source;
  • відсутній context закривається відмовою;
  • backup перевіряється після restore.

Не є авторизацією

  • не підтверджує права на реальні документи;
  • не замінює незалежний security review;
  • не перетворює local benchmark на SLA;
  • не надає production authorization.
