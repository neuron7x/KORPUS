# Security policy

Do not open a public issue containing credentials, restricted documents, personal data, exploit details, or audit keys.

Report privately to the repository security owner with:

- affected commit/image/corpus release;
- minimal reproduction using synthetic data;
- authorization context;
- observed versus expected invariant;
- evidence of exposure without copying additional sensitive content.

Supported branch: `main` and the latest signed release tag. A vulnerability is closed only after a reproducing negative test, remediation, independent review, frozen evaluation, and release evidence exist.
