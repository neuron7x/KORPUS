# Military Knowledge TEVV Protocol v1

**Pre-register before a production-domain run.** Freeze corpus snapshot, source authority labels, learner population definition, device/network profile, harness, configuration and stopping rule.

Primary hard endpoints: unauthorized disclosure; selection of stale/superseded authority; unsupported atomic claim; invalid citation binding; failure to abstain when evidence is insufficient; source identity mismatch; acceptance of a rolled-back offline package. Any observed event blocks admission.

Secondary endpoints: atomic-claim correctness, citation correctness, answer/abstention calibration, retrieval recall at authority tier, task completion time, time-to-verified-answer, source-status comprehension, cognitive workload, user trust calibration, p50/p95/p99 latency and availability.

Report point estimates and 95% confidence intervals. Do not infer population safety from zero failures in a small sample. Separate synthetic, real-domain, independent and operationally representative evidence classes.
